RITANI

 

Overview

It's a feature-rich e-commerce platform to sell diamond products especially engagement ring, wedding ring, bracelets, necklaces etc. A user can design products as per his preferences also can see the free preview in his nearest location. The application is developed on top of ruby on rails and spree ruby gem

URL: https://www.ritani.com/     Worked: 1 year 2 Month
 

Key Functional Responsibilities

  • Ruby on Rails version migration(rails 3.2 to 4.2 than 5). One of the most complex tasks which was the initial scope of my work on this project.
  • DOC and PDF Reporting for order delivery details with invoices including discount on the product based on payment type(Cash/Credit card/Bank wire). Used savlon gem ruby library which uses MSDoc template-based reporting.
  • The application has been using in production so many years and has user base so it was important to track the application usage history, page visit count etc. using Google analytics GA and GTM. It helps the product owner to analyze the application usage and future product enhancement opportunities.
  • Production issue investigation and high priority fix. Troubleshoot the issue and produce it on staging and development environment first then fix and deploy to production.
  • API documentation using APIrey and circle CI integration. None of the PR(pull request) was merged unless all of the test cases were passed. Most of the API's has dependency with other services so it was a bit complicated to make sure all the test run and delivery the work on time successfully.
  • Move REST API's of the application to a new rails application using GraphQL on top of the same data layer. In REST API it's important to document the API's and which gets complicated over the changes/modification/new version of API's. But in GraphQL we don't have to worry about that and it has no dependency with API developer and front-end developer(mobile or web app).
  • UI design implementation which was provided by zeplin. Due to the products rebranding, it was required to work on front-end design(mobile + web responsive) two month with the design team.
  • Large volume data indexing and free text search functionality using elasticsearch.
  • Technical lead of the development team in Bangladesh

Plexina Solutions

 

Overview

Plexina is a Platform for Enterprise Clinical Knowledge and Clinical Decision Support (CDS) Management. It is a combination of integrated software tools, a best practice methodology for CDS delivery and consulting services for optimizing CDS within clinical operations. In other words, Plexina is a software suite that supports clinical content management and governance by providing the ability to collaboratively develop, review, version, and optimize clinical content. The most advanced way to bring structure clinical decision support workflow. It helps clinicians to design better CDS tools, which in turn helps them make informed care decision, ultimately improving patient outcomes.

URL: https://plexinasolutions.com/     Worked: 3.5+ years
 

Key Functional Responsibilities

  • Reporting was one of the major features of plexina solutions. Which helps stakeholders to analyze order sets evolution, changes, duplication, EHR Preview etc. 30+ report which helps the physician and clinical analyst.
  • Standardized concepts integration SNOMED CT, ICD-10 LOINC etc.
  • HTML Document(generate using running one report) review process and review team management, notify each review team member for each review item.
  • PDF report generation using the wkhtmltopdf library
  • Production deployment for the individual client using Capistrano gem
  • Production issue troubleshoot and provide the solution as high priority
  • Desktop application to web application conversion using ruby on rails and angularJS as a single page app. Developed REST API using rails, angularJS, and Twitter Bootstrap as front-end app development.
  • Document design with drag and drop ability of the different type of predefined datasets
  • Technical lead of the development team in Bangladesh

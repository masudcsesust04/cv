Forex Feed System

 

Overview

A Forex Feed System is a real-time application that collects, processes, and distributes foreign exchange rate data from various providers like financial APIs or trading platforms. It fetches live currency pair prices, normalizes and validates the data, and then pushes updates to subscribers or internal services via WebSockets, RPC APIs, or message queues. The system supports high throughput, minimal latency, and fault tolerance. It often includes features like caching, rate-limiting, and historical data storage for analytics.

URL: Underlying Feed     Worked: 1 year 6 Month
 

Functional Scope

  • Migrate legacy monolithic system to microservices
  • gRPC with Protocol Buffers for high-performance internal communication between services.
  • A real-time streaming service using gRPC server-side streaming to deliver low-latency tick data.
  • gRPC endpoint for historical tick data, with time-based filtering.
  • gRPC proxy gateway to expose gRPC services as RESTful endpoints
  • Real-time and historical OHLC data gRPC and REST APIs.
  • OHLC for different granularity (1m, 5m, 1h, etc.) by tick aggregation.
  • Metadata service for tradable symbols, instrument types, and configurations.
  • Build a lightweight, secure admin dashboard to manage scheduled launches derived products.
  • Redis is extensivley used for caching

Overview

Plexina is a Platform for Enterprise Clinical Knowledge and Clinical Decision Support (CDS) Management. It is a combination of integrated software tools, a best practice methodology for CDS delivery and consulting services for optimizing CDS within clinical operations. In other words, Plexina is a software suite that supports clinical content management and governance by providing the ability to collaboratively develop, review, version, and optimize clinical content. The most advanced way to bring structure clinical decision support workflow. It helps clinicians to design better CDS tools, which in turn helps them make informed care decision, ultimately improving patient outcomes.
